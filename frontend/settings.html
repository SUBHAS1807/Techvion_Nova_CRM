Google Cloud Platform Setup Guide

To use Google Places API (New) for automated lead generation:

  1. Open the Google Cloud Console ↗ and create or select a project.
  2. Go to APIs & Services → Library and enable Places API (New).
  3. Ensure a billing account is linked (Google Cloud provides $200 recurring monthly free credit).
  4. Go to Credentials, generate an API Key, and paste it into the field above.
